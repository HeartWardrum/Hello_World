# 行测翻译推理技巧速查

可背练笔记：先找关联词 → 按规则翻译成箭头 → 用推理规则推必然结论 → 对照选项排除。

核心口诀：**先翻译，后推理。肯前必肯后，否后必否前，否前肯后不必然。**

---

## 1. 题型识别与做题顺序

### 怎么认出是翻译推理

- 题干或选项里有明显逻辑关联词：如果……那么……、只有……才……、除非……否则……、且 / 或、并非……
- 提问常是：可以推出 / 由此可知 / 不可能为真 / 以下哪项正确（选非）

### 三步做题

1. **翻译**：只盯带关联词的句子，用字母代替前后内容，写出 `A→B`、`A且B`、`A或B`
2. **推理**：优先逆否，含「且/或」否定时用摩根；多条箭头能串就递推
3. **对选项**：只认「必然推出」；肯后、否前、关联词偷换、无关信息一律排除

### 读题习惯

- 跳过背景铺垫、举例，**只抠逻辑句**
- 多条件先分别编号①②③，再看能否串成一条链
- 看清设问是「能推出」还是「不能推出 / 选非」

## 2. 翻译规则（把中文变成箭头）

### 2.1 前推后（充分条件）

含义：有 A 就一定有 B；没有 A，B 可有可无。

| 常见说法 | 译法 |
|---------|------|
| 如果 A，那么 / 就 / 则 B | A→B |
| 只要 A，就 B | A→B |
| 若 A，则 B；倘若 A…… | A→B |
| 凡是 / 所有 A 都是 B | A→B |
| A 是 B 的充分条件 | A→B |
| 一……就…… | 前→后 |

口诀：**如果就，前推后。**

### 2.2 后推前（必要条件）

含义：没有 A 就没有 B；有 A，B 仍不一定。必要条件写在箭头**后面**。

| 常见说法 | 译法 |
|---------|------|
| 只有 A，才 B | B→A |
| 不 A，就不 B（不……不……） | B→A |
| 除非 A，否则不 B | B→A |
| A 是 B 的必要 / 前提 / 基础 / 关键 / 核心 | B→A |
| 除非 A，才 B（同「只有才」） | B→A |

口诀：**只有才，后推前；必要条件放箭头后。**

示意：「只有努力，才能考上」→ `考上→努力`（不是「努力→考上」）。

### 2.3 「除非……否则……」专项（易错）

| 句式 | 译法 | 记忆 |
|------|------|------|
| 除非 A，否则不 B | B→A | 当「只有才」用，后推前 |
| 除非 A，否则 B | ¬A→B | 否前推后；也等价于 ¬B→A |
| 否则 B（省略除非） | 当「除非 A 否则 B」补全后再译 | 先补全关联词再动笔 |

变形口诀：**除非否则不 = 后推前；除非否则 = 否前推后。**

补「不」技巧（遇到「除非 A，否则 B」）：可先想成「除非 A，否则不不 B」，其中一个「不」凑成「否则不」，剩下一个「不」留在命题上 → 得到 `¬B→A`，与 `¬A→B` 互为逆否，等价。

### 2.4 且、或、要么、并非

| 类型 | 关联词举例 | 符号 | 真假要点 |
|------|-----------|------|----------|
| 联言（且） | 和、且、既……又……、不仅……而且……、虽然……但是…… | A且B | 全真才真，一假即假 |
| 相容或 | ……或……、或者……或者…… | A或B | 至少一个真；可同真 |
| 不相容（要么） | 要么 A，要么 B | 要么A要么B | 有且仅有一个真 |
| 负命题 | 并非、不是、不能说 | ¬A | 直接否定整个命题 |

注意：「虽然……但是……」在逻辑上仍是 **且**，转折语气不改真假要求。

## 3. 推理规则（怎么推必然结论）

### 3.1 逆否等价（用得最多）

- `A→B` 等价于 `¬B→¬A`
- 口诀：**肯前必肯后，否后必否前；否前、肯后 → 推不出必然**

对 `A→B` 四种操作：

| 操作 | 例子 | 能否必然推出 |
|------|------|--------------|
| 肯前 | 有 A | 必有 B |
| 否后 | 无 B | 必无 A |
| 否前 | 无 A | **不确定**（B 可有可无） |
| 肯后 | 有 B | **不确定**（A 可有可无） |

错误选项九成是「否前」或「肯后」，见到就优先排除。

### 3.2 递推（箭头串起来）

- `A→B`，`B→C` ⇒ `A→C`
- 题干里同一概念反复出现，优先「穿串」再逆否

示意：阻止减速→市民化；市民化→信息系统 ⇒ 阻止减速→信息系统；再否后得：无信息系统→没能阻止减速。

### 3.3 且 / 或 的推理

**且（联言）**

- 真：可拆成「A 真」「B 真」
- 要得到「A且B」为真，两项都得真
- 否定「A且B」→ 用摩根，不能只否一项就完事

**或（相容选言）**

- 口诀：**或为真，否一推一**（否定其中一项 → 另一项必真）
- 肯定其中一项 → **推不出**另一项真假（可同真）

**要么（不相容）**

- 否一推一（同或）
- 肯一必否另一（与相容或不同）

### 3.4 摩根定律（否定拆开）

- `¬(A且B) = ¬A 或 ¬B`
- `¬(A或B) = ¬A 且 ¬B`

口诀：**负号进去，且变或，或变且。**

常考场景：题干是 `成功→(支持且参与)`，选项否后 → `¬(支持且参与)` → `¬支持 或 ¬参与`；若选项写成「既不支持也不参与」（¬支持且¬参与），那是把「或」偷成「且」，排除。

## 4. 解题模板（按题貌套）

### 4.1 单箭头题

1. 译成 `A→B`
2. 选项里找：**肯前**或**否后**（及其逆否写法）
3. 排除：肯后、否前、前后颠倒、偷换充分必要

### 4.2 多条件递推题

1. 每句单独翻译并编号
2. 找重复项，串成最长链
3. 对整条链做肯前 / 否后；跨链条硬凑的选项排除

### 4.3 含且 / 或 的箭头题

例：`赵→(钱且孙且李)`

- 否后：`¬(钱且孙且李)` → `¬钱或¬孙或¬李`，进而由逆否得 `¬赵` 的路径要对应清楚
- 常见正确项形态：否定后件里任一项 → 否定前件（因为后件是「且」，缺一则后件假 → 否后必否前）
- 常见错误项：否前后乱推「全都没有」

### 4.4 「除非否则」题

先按 §2.3 译准，再当普通箭头题做；不要凭语感把「除非」当成「如果」。

### 4.5 选非题 / 「不能推出」

- 能推出的三项通常是：肯前、否后、逆否、合法递推
- 不能推出的那项往往是：肯后、否前、或肯一推另一、充分必要对调

## 5. 选项秒杀清单

按这个顺序扫选项最快：

1. **关联词偷换**：题干「只有 A 才 B」（B→A），选项改成「只要 A 就 B」（A→B）→ 杀
2. **肯后 / 否前**：直接杀
3. **摩根拆错**：该「或」写成「且」，该「且」写成「或」→ 杀
4. **递推乱串**：两段箭头没有公共项却硬推 → 杀
5. **无关信息**：选项扯题干没翻译的背景 → 杀
6. **必然 vs 可能**：题干推必然，选项改成「可能」「未必」且设问要必然 → 慎选或排除（看设问）

剩下能与题干箭头（或逆否）对齐的，就是答案。

---

## 6. 易错点清单

- **「只有才」译反**：写成努力→考上，其实是考上→努力
- **「除非否则」与「除非否则不」混用**：少一个「不」，箭头方向全变
- **否前当否后**：没努力 ≠ 一定考不上（对「考上→努力」而言，否后才是「不努力→考不上」）
- **肯后当肯前**：「在现场」推不出「是杀人犯」（杀人犯→在现场）
- **充分必要对调**：充分条件 ↔ 必要条件 说反
- **「或」肯一乱推**：A或B 为真且 A 真，推不出 B 假（相容或）
- **「要么」当「或」**：要么要互斥；或允许同真
- **否定且/或拆错**：¬(A且B) 不是 ¬A且¬B
- **递推漏中间项**或跨条件硬连
- **选非题看反**：把能推出的选成答案
- **日常语感干扰**：「除非」在口语里像条件，做题必须按翻译表，不按语感

## 7. 必背口诀（临场默念）

```
如果就，前推后；只有才，后推前。
除非否则不，后推前；除非否则，否前推后。
肯前肯后，否后否前；否前肯后，不必然。
或关系，否一推一；且关系，要全真。
负号进，且变或，或变且。
多箭头，重复项，穿成串。
```

## 8. 临场时间建议

| 环节 | 建议 |
|------|------|
| 单题 | 约 40～60 秒 |
| 超时 | 超过 1 分钟仍译不准 → 标记跳过，别死磕语感 |
| 下手顺序 | 先写箭头再看选项，不要边读选项边猜 |

核心原则：**翻译推理得分看「关联词译准 + 只推必然」，不看谁更像生活常识。**
