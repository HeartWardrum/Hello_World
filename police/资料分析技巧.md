# 行测资料分析技巧速查

可背练笔记：先定位数据 → 套公式 → 选速算方法 → 对照选项。

---

## 1. 读材料与做题顺序

### 做题顺序

1. **先看题，再找数**：题干时间、主体、指标先圈定，再回材料定位。
2. **简单题先做**：直接读数、简单加减、明显大小比较优先拿分。
3. **综合分析后置**：往往要验证 3～4 个表述，放到本篇材料最后做。

### 材料怎么扫

| 材料类型 | 扫读重点 |
|---------|---------|
| 文字材料 | 时间、主体、单位、同比/环比、累计/当期；段落首句常是总分 |
| 表格 | 表头行列含义、单位、备注；先找“合计/总计/平均”行 |
| 图形 | 图例、坐标单位、时间轴；柱状看绝对量，折线看趋势，饼图看结构 |

### 定位口诀

- 问 **谁**（主体）→ 在材料哪一段/哪一行
- 问 **哪年/哪月**（时间）→ 现期还是基期
- 问 **什么指标**（产值、人数、金额……）→ 别串列
- 问 **同比还是环比** → 基期选错全盘错

## 2. 核心概念

| 概念 | 一句话含义 | 怎么算 |
|------|-----------|--------|
| 现期量 | 题目问的那个时间的数 | 材料里直接读，或用基期推 |
| 基期量 | 用来对比的上一年/上一期的数 | 现期 ÷ (1 + 增长率) |
| 增长量 | 比基期多了（或少了）多少 | 现期 − 基期 |
| 增长率（增速） | 比基期多了百分之几 | 增长量 ÷ 基期 |
| 同比 | 跟去年同一时期比 | — |
| 环比 | 跟上一个统计周期比 | — |
| 比重 | 部分占整体多少 | 部分 ÷ 整体 |
| 倍数 | A 是 B 的几倍 | A ÷ B |
| 平均数 | 平均每个多少 | 总量 ÷ 份数 |

关系速记（背这三句就够）：

- 现期 = 基期 × (1 + 增长率)
- 基期 = 现期 ÷ (1 + 增长率)
- 增长量 = 基期 × 增长率 = 现期 × 增长率 ÷ (1 + 增长率)

## 3. 必背公式速查

### 3.1 增长量与增长率

- 增长率 = (现期 − 基期) ÷ 基期 = 现期 ÷ 基期 − 1
- 增长量 = 现期 − 基期 = 现期 × 增长率 ÷ (1 + 增长率)
- 已知增长量求增长率：增长率 = 增长量 ÷ 基期 = 增长量 ÷ (现期 − 增长量)

### 3.2 基期量 / 现期量

- 基期 = 现期 ÷ (1 + 增长率)
- 现期 = 基期 × (1 + 增长率)
- 已知基期和增长量：现期 = 基期 + 增长量

### 3.3 间隔增长率

从基期到现期中间隔了一年（如 2022→2024），两年增速分别是 r1、r2：

- 间隔增长率 = r1 + r2 + r1 × r2

示意：10% + 20% + 10%×20% = 32%

### 3.4 年均增长率

从基期到现期经过 n 年，年均增长率 r 满足：

- 基期 × (1 + r)^n = 现期
- 也就是：(1 + r)^n = 现期 ÷ 基期

怎么用：

- **精确**：开方，或把选项代入验算
- **近似**（增速不大时）：年均增长率 ≈ (现期 ÷ 基期 − 1) ÷ n，结果会略偏大，只适合估算

注意：年均增长 **率** 用上面；年均增长 **量** = (现期 − 基期) ÷ n

### 3.5 混合增长率

整体由两部分拼起来，两部分增速不同，整体增速：

- 一定落在两部分增速 **之间**
- 更靠近 **基期量大** 的那一边

十字交叉（粗算可用现期量代替基期量，但要知道有误差）：

- (整体增速 − 乙增速) : (甲增速 − 整体增速) ≈ 甲的基期量 : 乙的基期量

口诀：混合增速 = 两边增速的加权平均，基期大的那边更“拽”。

### 3.6 比重

- 现期比重 = 部分现期 ÷ 整体现期
- 基期比重 = 部分基期 ÷ 整体基期 = 现期比重 × (1 + 整体增速) ÷ (1 + 部分增速)

比重差（单位：百分点）：

- 比重差 = 现期比重 × (部分增速 − 整体增速) ÷ (1 + 部分增速)

升降判断（不用先算两个比重）：

- 部分增速 **大于** 整体增速 → 比重上升
- 部分增速 **小于** 整体增速 → 比重下降

### 3.7 平均数与倍数

- 平均数 = 总量 ÷ 份数
- 倍数 = A ÷ B

倍数措辞别搞混：

- “A 比 B 增长了 n 倍” → A = B × (1 + n)，也就是 A 是 B 的 (n + 1) 倍
- “A 是 B 的 n 倍” → A = n × B，A 比 B 多 (n − 1) 倍

平均数的增长率（总量增速、份数增速分别已知）：

- 平均数增长率 = (总量增速 − 份数增速) ÷ (1 + 份数增速)

## 4. 速算技巧

### 4.1 截位直除

**适用**：除法（求增长率、比重、倍数、基期等），选项有差距时。

一句话：先看选项差距定截几位 → 分子分母同截保量级 → 直除到能锁选项就停。四选一几乎从不需要算到精确值。

**步骤**：

1. 看选项差距：首位不同 → 截 2 位；前两位接近 → 截 3 位
2. 分子分母同时截位（量级一起看，不要只截一边）
3. 直除到能区分选项就停

#### 先看选项，再决定截几位

| 选项情况 | 截位 | 目的 |
|---------|------|------|
| 首位就不同（如 6.x / 7.x / 8.x） | 截 **2** 位 | 最快出首位 |
| 前两位接近（如 12.3% / 12.8% / 13.1%） | 截 **3** 位 | 区分第二、三位 |
| 咬得很死（差 0.1 个百分点级） | 截 3～4 位或短除多除一位 | 少见，资料分析多数用不上 |

口诀：**差得大截得少，差得小截得多**。

#### 怎么截（最容易错）

- **上下一起截**，只截一边会漂数量级（如只把 4832 截成 48、分母仍用 761 → 量级错）。
- 截的是**有效数字**，不是简单砍尾巴：`761 → 7.6`（保留两位）或 `76`（再自己对量级）。
- 量级对齐示意：`4832 ÷ 761` → 看成 `48 ÷ 7.6`（都缩小 100 倍），商不变。
- 分母截成「好除」的数更佳：`7.6` 可心算成 `76÷10`，或近似 `7.5` 再微调。

#### 直除手法（四选一专用）

1. 估首位：分母「进一」试除（如 `48÷7.6`，先想 `7.6×6=45.6`，余约 2.4 → 商约 **6.3**）。
2. **能唯一对应选项就停**，不要继续除小数。
3. 选项是百分数时：算的是 `现期/基期` 再减 1，或直接比 `增长量/基期`；截位规则相同。
4. 若四选项呈「偏大/偏小」对称，用放缩判断方向：分子偏大估 → 商偏大，对照选项排除。

#### 常见题型套用

- **增长率**：(现期−基期)/基期 或 现期/基期−1 → 截位直除
- **比重 / 倍数 / 基期**：现期÷(1+r) → 同样截位除
- **比较谁更大**：两个分数各截位直除比商，或改用同位/差分（§4.5～4.6）

#### 易错清单

- 只截分子不截分母（量级飞了）
- 选项首位不同却截了 3～4 位（浪费时间）
- 截完忘了「同缩同放」，把 `48÷7.6` 又当成 `480÷7.6`
- 求增长率时算出 `现期/基期≈1.12` 却选成 `12` 或忘了减 1 / 化成 %
- 负增长时 `÷(1+r)` 且 `1+r<1`，基期大于现期，商方向别凭感觉

#### 背练例

- 首位可分：`4832÷761 ≈ 48÷7.6 ≈ 6.3`（选项若 5.8 / 6.3 / 7.2 / 8.0 → 锁 6.3）
- 前两位接近：`3256÷268 ≈ 326÷27 ≈ 12.1`（若选项 11.8% / 12.1% / 12.5% / 13.0% 一类，需多除半位）

### 4.2 特殊分数（百化分基础）

| 分数 | 百分数 | 分数 | 百分数 |
|------|--------|------|--------|
| 1/2 | 50% | 1/3 | 33.3% |
| 1/4 | 25% | 1/5 | 20% |
| 1/6 | 16.7% | 1/7 | 14.3% |
| 1/8 | 12.5% | 1/9 | 11.1% |
| 1/11 | 9.1% | 1/12 | 8.3% |
| 1/13 | 7.7% | 1/14 | 7.1% |
| 1/15 | 6.7% | 1/16 | 6.25% |
| 1/17 | 5.9% | 1/18 | 5.6% |
| 1/19 | 5.3% | 1/20 | 5% |

邻近值可估：15% ≈ 1/6.7，12% ≈ 1/8.3

### 4.3 百化分（算增长量神器）

**适用**：已知现期、增长率，求增长量。

正常公式：增长量 = 现期 × 增长率 ÷ (1 + 增长率)

**速算**：把增长率化成 1/n，则

- 增长量 ≈ 现期 ÷ (n + 1)

示意：增长率 12.5% = 1/8 → 增长量 ≈ 现期 ÷ 9

### 4.4 放缩法

**适用**：比较大小、排除选项。

- 分子变大 / 分母变小 → 分数变大
- 同向放缩时注意方向是否一致，避免误判
- 多步运算可先放大或缩小到整十整百再算

### 4.5 差分法

**适用**：比较两个分数 a/b 和 c/d 谁大（且 a > c > 0，b > d > 0）。

拿“多出来的部分”再做一个分数：(a − c) ÷ (b − d)，跟原来的 c/d 比：

- (a − c)/(b − d) 更大 → a/b 更大
- (a − c)/(b − d) 更小 → a/b 更小

### 4.6 同位比较

**适用**：多个分数比大小，分子分母位数接近。

对齐数量级后比“首位 ÷ 首位”，或截位后直除，谁大谁增速/倍数大。

### 4.7 拆分法

**适用**：接近整十、整百的乘法；或算 现期 ÷ (1 + 增长率) 且增长率不大时。

示意：

- 483 × 1.02 = 483 + 483 × 0.02
- 500 ÷ 1.05 ≈ 500 × (1 − 0.05) = 475（增速小时够用）

### 4.8 错位加减

**适用**：多位数加减，或材料中多项求和。

低位对齐、同级相加；可先加整数部分再处理小数/单位换算。

### 4.9 增长率比较技巧

比较谁增速大，本质是比：现期 ÷ 基期（再减 1 也行，比大小时减不减一样）。

1. **直除**：截位算 现期 ÷ 基期
2. **增量感觉**：基期差不多时，增长量大的增速通常更大
3. **倍数感觉**：现期明显大很多的，往往增速也大（临界题仍要用除法确认）

## 5. 题型解题模板

### 5.1 基期 / 现期

| 已知 | 所求 | 怎么做 |
|------|------|--------|
| 现期、增长率 | 基期 | 现期 ÷ (1 + 增长率)，截位直除 |
| 基期、增长率 | 现期 | 基期 × (1 + 增长率)，拆分或估算 |
| 现期、增长量 | 基期 | 现期 − 增长量 |

注意：增长率为负时，1 + 增长率小于 1，基期 **大于** 现期。

### 5.2 增长量

1. 优先：现期、增长率已知 → 百化分，增长量 ≈ 现期 ÷ (n + 1)
2. 其次：现期、基期已知 → 现期 − 基期
3. 比较增长量：都化成百化分后比 现期 ÷ (n + 1)

### 5.3 增长率

1. 现期、基期已知 → 现期 ÷ 基期 − 1，截位直除
2. 间隔增速 → r1 + r2 + r1 × r2
3. 混合增速 → 先定在两边之间，再偏向基期大的一边；要精确再用十字交叉
4. 部分与整体：由比重升或降，反推谁增速更高

### 5.4 比重升降与差值

1. **升降**：直接比部分增速和整体增速，不用先算两个比重
2. **差值**：现期比重 × (部分增速 − 整体增速) ÷ (1 + 部分增速)；选项差距大时可估算
3. 单位是 **百分点**，别和百分数混用

### 5.5 平均数 / 倍数

- 平均数：总量 ÷ 份数；注意分子分母是否同一口径
- 平均数增长率：(总量增速 − 份数增速) ÷ (1 + 份数增速)
- 倍数：A ÷ B；问“多几倍”要再减 1
- 基期倍数：现期倍数 × (1 + B 的增速) ÷ (1 + A 的增速)

### 5.6 综合判断

1. **找最容易验证的表述**（直接读数、明显不对的趋势）
2. 涉及计算的表述用估算排除，不必精算到小数点后很多位
3. 注意“正确的是 / 不正确的是”，看清设问
4. 时间、单位、同比环比任一不符即可判错

## 6. 易错点清单

- **时间错位**：问 2023 年却用了 2024 年数据；累计 1–6 月当成 6 月
- **同比 / 环比搞混**：基期选错
- **单位**：万 / 亿、元 / 万元、% / 百分点
- **部分与整体**：用错行合计，或拿 A 行业除以全国时分母不是全国
- **增长量 vs 增长率**：问“增加了多少”是量，问“增长了百分之几”是率
- **倍数表述**：“增长了 2 倍”≠“是原来的 2 倍”
- **基期比重算成现期比重**：忘记再乘 (1 + 整体增速) ÷ (1 + 部分增速)
- **负增长**：1 + 增长率小于 1，除法方向与正增长直觉相反
- **选项词**：“约”“超过”“不到”“以上均正确”——估算后要对照临界
- **图表误读**：图例颜色对错行、双轴图看错坐标

## 7. 临场时间建议

| 环节 | 建议 |
|------|------|
| 单篇材料 | 约 5～7 分钟（含综合分析） |
| 单题超时 | 超过 1 分钟仍无思路 → 标记跳过 |
| 算到哪步停 | 能唯一对应选项就停，不要追求精算 |

核心原则：**资料分析得分看“定位准 + 速算稳”，不看竖式有多漂亮。**
