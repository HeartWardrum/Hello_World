## 使用建议

1. **只打开题目文件**做完；再打开对应 `*-答案.md` 核对。
2. 先定位数据 → 套公式 → 截位/百化分速算 → 对照选项。
3. 综合分析题放到该篇最后做；拿不准先排除明显错项。
4. 算不快可穿插 `police/速算` 模块练手感。
5. 后续可按同格式继续追加材料。
