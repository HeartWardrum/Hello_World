## 使用建议

1. **只打开题目文件**刷完；再打开对应 `*-答案.md` 核对。
2. 江苏 B 类逻辑判断卷内约 15 题，**加强削弱**通常最多，优先刷。
3. 答案文件含选项字母、简析与来源链接；疑义以原页为准。
4. 后续可按同格式继续追加。
