我来帮你写一个完整的PowerShell脚本，用于自动同步Git仓库并提交本地修改。

## 脚本文件：`AutoGitSync.ps1`

```powershell
# ============================================
# Git 自动同步脚本 - 支持多仓库
# 功能：自动拉取远程更新、提交本地修改、推送到远程
# 特点：无感知执行（不弹出任何窗口提示）
# 使用方法：配置下方的仓库列表，然后通过任务计划程序定时执行
# ============================================

# ========== 配置区域 - 请在这里添加你的仓库路径 ==========
$repos = @(
    "D:\Projects\repo1",           # 仓库1路径
    "E:\Work\repo2",               # 仓库2路径
    "C:\Users\用户名\Documents\repo3"  # 仓库3路径
    # 继续添加更多仓库路径...
)

# 日志文件路径（可选，用于调试，设为 $null 则不记录日志）
$logFile = "$env:TEMP\AutoGitSync.log"

# 是否启用详细日志（$true=记录详细日志，$false=只记录错误）
$enableVerboseLog = $false

# ========== 函数：写入日志 ==========
function Write-Log {
    param(
        [string]$Message,
        [string]$Level = "INFO"
    )
    
    if ($null -eq $logFile) { return }
    
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    $logMessage = "[$timestamp] [$Level] $Message"
    
    try {
        Add-Content -Path $logFile -Value $logMessage -ErrorAction SilentlyContinue
    }
    catch {
        # 静默失败，不抛出错误
    }
}

# ========== 函数：测试网络连接 ==========
function Test-NetworkAvailable {
    try {
        $test = Test-Connection -ComputerName "github.com" -Count 1 -Quiet -ErrorAction SilentlyContinue
        if (-not $test) {
            $test = Test-Connection -ComputerName "gitlab.com" -Count 1 -Quiet -ErrorAction SilentlyContinue
        }
        return $test
    }
    catch {
        return $false
    }
}

# ========== 函数：同步单个仓库 ==========
function Sync-GitRepository {
    param(
        [string]$RepoPath
    )
    
    # 检查路径是否存在
    if (-not (Test-Path $RepoPath)) {
        Write-Log "路径不存在: $RepoPath" -Level "ERROR"
        return $false
    }
    
    # 检查是否为Git仓库
    $gitDir = Join-Path $RepoPath ".git"
    if (-not (Test-Path $gitDir)) {
        Write-Log "不是Git仓库: $RepoPath" -Level "ERROR"
        return $false
    }
    
    # 保存当前目录
    $currentDir = Get-Location
    
    try {
        Set-Location $RepoPath
        
        # 获取当前分支名
        $branch = & git rev-parse --abbrev-ref HEAD 2>$null
        if (-not $branch) {
            Write-Log "无法获取当前分支: $RepoPath" -Level "ERROR"
            return $false
        }
        
        Write-Log "开始同步仓库: $RepoPath [$branch]"
        
        # 1. 检查是否有未提交的更改
        $status = & git status --porcelain 2>$null
        
        # 2. 拉取远程更新（使用rebase策略，避免不必要的merge commit）
        $pullResult = & git pull --rebase --no-edit 2>&1
        $pullExitCode = $LASTEXITCODE
        
        if ($pullExitCode -ne 0) {
            Write-Log "拉取失败: $RepoPath - $pullResult" -Level "WARN"
            
            # 尝试使用普通pull
            $pullResult = & git pull --no-edit 2>&1
            $pullExitCode = $LASTEXITCODE
            
            if ($pullExitCode -ne 0) {
                Write-Log "拉取失败（重试后）: $RepoPath" -Level "ERROR"
                return $false
            }
        }
        
        # 3. 如果有本地修改，则提交
        if ($status) {
            Write-Log "检测到本地修改: $RepoPath"
            
            # 添加所有修改（包括新增、删除、修改）
            & git add -A 2>&1 | Out-Null
            
            # 生成提交信息（包含时间戳）
            $commitMsg = "Auto-sync: $(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')"
            $commitResult = & git commit -m $commitMsg 2>&1
            $commitExitCode = $LASTEXITCODE
            
            if ($commitExitCode -eq 0) {
                Write-Log "提交成功: $RepoPath"
                
                # 4. 推送到远程
                $pushResult = & git push 2>&1
                $pushExitCode = $LASTEXITCODE
                
                if ($pushExitCode -eq 0) {
                    Write-Log "推送成功: $RepoPath"
                    return $true
                }
                else {
                    # 尝试设置上游并推送
                    $pushResult = & git push --set-upstream origin $branch 2>&1
                    $pushExitCode = $LASTEXITCODE
                    
                    if ($pushExitCode -eq 0) {
                        Write-Log "推送成功（设置上游）: $RepoPath"
                        return $true
                    }
                    else {
                        Write-Log "推送失败: $RepoPath - $pushResult" -Level "ERROR"
                        return $false
                    }
                }
            }
            else {
                Write-Log "提交失败: $RepoPath - $commitResult" -Level "ERROR"
                return $false
            }
        }
        else {
            Write-Log "无本地修改: $RepoPath"
            return $true
        }
    }
    catch {
        Write-Log "同步异常: $RepoPath - $_" -Level "ERROR"
        return $false
    }
    finally {
        Set-Location $currentDir
    }
}

# ========== 主程序 ==========

# 重定向所有输出流到null（实现真正的无感知）
if ($env:IS_SILENT_MODE -ne "1") {
    $null = Start-Process -FilePath "powershell.exe" -ArgumentList "-NoProfile -ExecutionPolicy Bypass -File `"$PSCommandPath`" -SilentMode" -WindowStyle Hidden -PassThru
    exit
}

# 静默模式执行
try {
    # 检查网络连接
    if (-not (Test-NetworkAvailable)) {
        Write-Log "网络不可用，跳过同步"
        exit 0
    }
    
    $successCount = 0
    $failCount = 0
    $startTime = Get-Date
    
    Write-Log "========== 开始同步任务 =========="
    
    foreach ($repo in $repos) {
        Write-Log "处理仓库: $repo"
        if (Sync-GitRepository -RepoPath $repo) {
            $successCount++
        }
        else {
            $failCount++
        }
        
        # 仓库之间稍微延迟，避免并发问题
        Start-Sleep -Milliseconds 500
    }
    
    $endTime = Get-Date
    $duration = ($endTime - $startTime).TotalSeconds
    
    Write-Log "========== 同步完成 =========="
    Write-Log "成功: $successCount 个仓库，失败: $failCount 个仓库"
    Write-Log "耗时: $duration 秒"
    
    # 清理旧日志（保留最近30天）
    if ($logFile -and (Test-Path $logFile)) {
        $logRetentionDays = 30
        $cutoffDate = (Get-Date).AddDays(-$logRetentionDays)
        $logContent = Get-Content $logFile -ErrorAction SilentlyContinue
        if ($logContent) {
            $filteredLog = $logContent | Where-Object {
                if ($_ -match '^\[(\d{4}-\d{2}-\d{2})') {
                    $logDate = [DateTime]::ParseExact($matches[1], "yyyy-MM-dd", $null)
                    return $logDate -gt $cutoffDate
                }
                return $true
            }
            $filteredLog | Set-Content $logFile -ErrorAction SilentlyContinue
        }
    }
}
catch {
    Write-Log "脚本执行异常: $_" -Level "ERROR"
}

exit 0
```

## 使用方法

### 1. 配置脚本
编辑 `AutoGitSync.ps1` 文件，在 `$repos` 数组中添加你的仓库路径：

```powershell
$repos = @(
    "D:\Projects\my-project",
    "E:\Work\company-project",
    "C:\Users\你的用户名\Documents\personal-project"
)
```

### 2. 测试运行
```powershell
# 手动测试（会显示输出）
powershell -ExecutionPolicy Bypass -File "D:\Scripts\AutoGitSync.ps1"

# 静默测试（无窗口）
powershell -ExecutionPolicy Bypass -WindowStyle Hidden -File "D:\Scripts\AutoGitSync.ps1"
```

### 3. 设置Windows任务计划程序

**步骤：**

1. 打开"任务计划程序"（Win + R，输入 `taskschd.msc`）
2. 点击"创建任务"
3. 配置如下：

**常规选项卡：**
- 名称：`Git自动同步`
- 描述：`自动同步所有配置的Git仓库`
- 安全选项：勾选"不管用户是否登录都要运行"
- 勾选"使用最高权限运行"

**触发器选项卡：**
- 新建触发器
- 设置为：`按预定计划` -> `每天` 或 `每30分钟`
- 根据需要设置开始时间

**操作选项卡：**
- 新建操作
- 操作：`启动程序`
- 程序或脚本：`powershell.exe`
- 添加参数：`-NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "D:\Scripts\AutoGitSync.ps1" -SilentMode`
- 起始于：`D:\Scripts`（改成你的脚本目录）

**条件选项卡：**
- 建议取消勾选"只有在计算机使用交流电源时才启动"
- 勾选"唤醒计算机运行此任务"（可选）

**设置选项卡：**
- 勾选"允许按需运行任务"
- 勾选"如果任务运行时间超过X小时，停止任务"（设置1小时）
- 勾选"如果任务运行失败，按以下频率重启"（设置3次，间隔5分钟）

### 4. 高级配置

#### 配置Git全局设置（避免弹出凭据对话框）
```bash
# 使用凭据管理器缓存凭据
git config --global credential.helper manager

# 或者使用个人访问令牌（推荐）
# 在远程URL中包含令牌：https://TOKEN@github.com/user/repo.git
```

#### 配置日志查看
```powershell
# 查看最新日志
Get-Content $env:TEMP\AutoGitSync.log -Tail 50

# 清除日志
Remove-Item $env:TEMP\AutoGitSync.log
```

## 注意事项

1. **首次运行需要配置Git凭据**，否则推送会失败
2. **冲突处理**：脚本使用 rebase 策略，如果有冲突需要手动解决
3. **大文件**：避免提交大文件，可能会导致超时
4. **网络安全**：确保防火墙允许Git连接
5. **权限设置**：脚本需要执行策略权限，使用 `Set-ExecutionPolicy RemoteSigned`

## 故障排查

如果脚本不工作，检查以下几点：

1. **Git是否已安装**：打开CMD，输入 `git --version`
2. **路径是否正确**：检查仓库路径是否存在且是Git仓库
3. **网络连接**：确保能访问Git服务器
4. **查看日志**：检查 `%TEMP%\AutoGitSync.log` 文件
5. **手动测试**：先手动运行脚本，看是否有错误提示

这个脚本已经完全配置为无感知执行，不会弹出任何窗口或提示。你只需要修改仓库路径，然后设置定时任务即可。
