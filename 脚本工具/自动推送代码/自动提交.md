## 精简版脚本：`AutoGitSync.ps1`

```powershell
# ========== 在这里添加你的仓库路径 ==========
$repos = @(
    "D:\Projects\repo1",
    "D:\Projects\repo2"
)

# ========== 脚本开始 ==========
foreach ($repo in $repos) {
    if (Test-Path $repo) {
        Push-Location $repo
        
        # 拉取远程更新
        git pull --no-edit
        
        # 提交本地修改
        git add .
        git commit -m "auto sync $(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')"
        
        # 推送到远程
        git push
        
        Pop-Location
    }
}
```

## 最简版（一行解决）

```powershell
# 单仓库版本
cd D:\Projects\repo1; git pull; git add .; git commit -m "auto sync"; git push
```

## 用于定时任务的静默执行脚本

```batch
@echo off
powershell -WindowStyle Hidden -File "D:\AutoGitSync.ps1"
```

## 配置步骤

1. **修改脚本中的仓库路径**（改成你的内网Git仓库地址）
2. **首次运行前**，先在命令行手动执行一次，输入用户名密码（或者配置好凭据）
3. **添加Windows定时任务**：
   - 程序：`powershell.exe`
   - 参数：`-WindowStyle Hidden -File "D:\AutoGitSync.ps1"`

就这么简单。内网用完全够了。
